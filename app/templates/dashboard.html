Claude Code — the launcher (Windows, macOS, Linux)

You need the Claude Code CLI installed (claude). The launcher asks for your gateway API key the first time it does not find one (in the AI_GATEWAY_API_KEY environment variable, or ~/.qwen/.env).

Windows (PowerShell)

  1. Download claude-gateway.ps1.
  2. Open PowerShell in the project you want to work on and run:
  3. Another model: add -Model qwen3-coder:30b -Context 32768. Anything else you add goes to claude as typed, e.g. -p "fix the failing test".

macOS and Linux (bash)

  1. Install it once:
  2. In the project you want to work on, run claude-gateway (if ~/.local/bin is not on your PATH, run it as ~/.local/bin/claude-gateway).
  3. Another model: add --model qwen3-coder:30b --context 32768. Anything else you add goes to claude as typed, e.g. -p "fix the failing test".

Everything it sets is for that one claude only, in a settings folder of its own (~/.claude-gateway): your usual Claude Code, signed in to claude.ai, is untouched. That separate folder matters — signed in to claude.ai, Claude Code sends that login instead of your gateway key, and the gateway refuses it.

Claude desktop app

The desktop app takes a gateway only for the whole app, not per project: Help → Troubleshooting → Enable Developer Mode, then Developer → Configure Third-Party Inference:

  • Inference provider: Gateway
  • Gateway base URL:
  • Gateway API key: one of your keys above, auth scheme Bearer
  • Models: the app accepts only names that look like Claude's, so write a gateway model as claude- and its name with : and . as -: claude-gemma4-31b is gemma4:31b, claude-qwen3-next-80b is qwen3-next-80b. Put the real name in Display name. Any other claude-* name, e.g. claude-sonnet-4-5, runs the gateway's default model.
  • Images need a model that sees them (vision in the model list above), e.g. claude-gemma4-31b; qwen3-next-80b reads text only.
  • Leave Offer 1M-context variant off: no model here has a 1M window.

This moves every desktop session — Code and Cowork — to this gateway, and Remote Control and cloud sessions are unavailable while it is on. Switch it back in the same place. To keep the desktop app on Claude, use the CLI with the launcher instead.
