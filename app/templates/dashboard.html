Connect an AI agent

Coding agents can use this gateway's models with one of your API keys above. Use a model that can call tools (the list above says tools), and tell the agent its real context size.

Applications — start an agent on one of these models

1Install the launcher — once per computer. It asks for your API key the first time (or reads AI_GATEWAY_API_KEY) and can keep it for next time.

2Start an app on a model, in the folder you want to work in.

Each app is pointed at this gateway in a place of its own, so the way you use it otherwise is untouched: Claude Code in ~/.claude-gateway, Hermes in ~/.hermes-gateway; OpenCode, Qwen Code and Codex for that one run only. OpenClaw keeps one config, so an ai-gateway provider is added to it (backed up first). An app that is not installed is not installed for you: the launcher prints its install command. Add --config to set an app up without starting it, and anything after -- goes to the app as typed. ai-gateway models lists what you may use.

Claude desktop app

The desktop app takes a gateway only for the whole app, not per project: Help → Troubleshooting → Enable Developer Mode, then Developer → Configure Third-Party Inference:

  • Inference provider: Gateway
  • Gateway base URL:
  • Gateway API key: one of your keys above, auth scheme Bearer
  • Models: the app accepts only names that look like Claude's, so write a gateway model as claude- and its name with : and . as -: claude-gemma4-31b is gemma4:31b, claude-qwen3-next-80b is qwen3-next-80b. Put the real name in Display name. Any other claude-* name, e.g. claude-sonnet-4-5, runs the gateway's default model.
  • Images need a model that sees them (vision in the model list above), e.g. claude-gemma4-31b; qwen3-next-80b reads text only.
  • Leave Offer 1M-context variant off: no model here has a 1M window.

This moves every desktop session — Code and Cowork — to this gateway, and Remote Control and cloud sessions are unavailable while it is on. Switch it back in the same place. To keep the desktop app on Claude, use the CLI with the launcher instead.
