Tool servers

MCP servers this gateway can call. Published ones and your own, side by side.

Servers are listed in config/mcp.yaml on the gateway. Secrets do not go in it: write ${NAME} and it is read from the environment or from config/config.properties, neither of which is in the repository.
This host has uvx and Docker but no node, so Python servers run directly, and anything published to npm runs in a container.
