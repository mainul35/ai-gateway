Tool servers

MCP servers this gateway can call. Published ones and your own, side by side.

Saved to config/mcp.yaml on the gateway, which stays readable and editable by hand. Secrets do not go in it: write ${NAME} and the value is read at connect time from the environment or from config/config.properties, neither of which is in the repository.
This host has uvx and Docker but no node: Python servers run directly, anything published to npm runs in a container. A stdio server is a command this gateway runs as its own user.
