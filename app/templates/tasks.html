GitHub access

The gateway reads repositories with these tokens (for the knowledge base) and pushes branches and opens pull requests with them (for tasks). Make one at GitHub → Fine-grained tokens: choose the resource owner, the repositories, and Contents and Pull requests: read and write. Owner here is that resource owner - your user name, or an organisation's name for a token made for the organisation; leave it empty and it is found from the token. An owner can have several tokens, each for different repositories: for each repository the gateway uses the one that reaches it. A token is checked with GitHub before it is saved, and never shown again in full.
